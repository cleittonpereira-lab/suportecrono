# Project Memory

## Core
Marca Suporte INFRA (carvão + âmbar). Suportar tema claro/escuro; logo preto vira branco no dark.
Backend = Lovable Cloud. Nunca citar "Supabase" ao usuário.
Prazo padrão de atraso = 5 dias úteis (não 4). Semana útil exclui sáb/dom/feriados; capacidade fracionária (0,25d = 4 ensaios/dia).
SLA relatório: Digitação 3d úteis; Verificação+Aprovação 2d úteis.
Massa específica sempre com ρ (rho grego), nunca γ.
Sub-abas: Relatório → Digitação & Emissões (unificada) e Digitalização (QR/Pendências/Cápsulas).
Papéis do Relatório (aprovador/verificador/digitador), Título e Cargo: só admin edita.
Cleitton Pereira (cleitton.pereira@suportesolos.com.br) = "Engº Geotécnico Cleitton Pereira", aprovador.
Google Drive sync desligado (flag VITE_ENABLE_DRIVE_SYNC=false) até novo pedido.
Operador de ensaio = técnico da programação do Gantt, nunca sobrescrever com usuário logado.
